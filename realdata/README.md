# realdata/ —— 真实行业数据（印证用，非仿真）

这里的每个子目录是一份**从公开渠道抓取的真实行业数据**，用途只有一个：
校验本技能面对真实数据时的健壮性、覆盖度与口径合理性。
它们**不是**仿真数据，`truth.json` 通常缺失（真实数据一般不给真值）。

来源与校验规则见 `scripts/realdata_check.py` 模块头，方法论见
`docs/真实数据印证-用行业数据校验技能.md`。

## 铁律

1. **没有 `source.json` 的用例一律拒收**——说不清来路的数据，其结论无法追溯。
2. **残缺数据必须声明** `truncated: true` + `truncation_note`，且不得用于统计显著性结论。
3. **不编数据**。抓不到就记"抓不到"，不塞来路不明的东西。

## 用例清单

### secom_uci —— 真实半导体晶圆厂制程数据

- 来源：UCI Machine Learning Repository，SECOM 数据集
  <https://archive.ics.uci.edu/dataset/179/secom>
- 原规模：1567 样本 × 591 个匿名化制程参数，标签 +1=合格 / -1=不合格
- 本目录规模：**160 行 × 590 列**（列数完整）
- **状态：已声明残缺**。原始 zip 约 9 MB，本机下载经代理在 ~1 MB 处被截断
  （zip 缺中央目录），用 deflate 部分解压得到前若干完整行。
  因此本用例**只用于健壮性与列名覆盖度印证，不作统计显著性结论**。
- 许可：CC BY 4.0（UCI 数据集页标注）。此处仅作技术验证使用，未作修改性再分发。
- 关键结论：
  - 列名被匿名化为 `X1..X590`（UCI 为保密未公开参数名）→ **列→参数命中 0/590**。
    这说明"按列名映射知识库"在真实 fab 数据上注定失败——
    **匿名数据只能靠人告知列含义**，加别名解决不了。
  - 含 4.9% `"NaN"` 与 `"Infinity"` → 打崩过 `quality_guard` 与图表坐标轴（已修，
    回归见 `scripts/selftest.py::test_realworld_dirty_values`）。
