# 8D 报告模板

> 本模板用于**对外**（客户/内部正式结案）的排版与归档。
>
> v1.13 起主报告第 12 节已覆盖 **D1–D8**：D2 走 `8D_D2录入卡.md` 并与数据交叉校验，
> D5–D8 由引擎生成**待验证方案 / 动作清单 / 结案条件**。
> 本模板用于把这些内容整理成对外版式，并补齐对外必填项（客户、签字、文件编号）。
>
> **D5–D8 未经人工确审（四项全 yes）不得对外发出。** 以结论口吻代填 D5–D8
> 在客户审核时是直接失分项。

## 附：常见退稿原因（本模板刻意规避的）

| 退稿原因 | 模板中的对应要求 |
|---|---|
| 问题描述无 5W2H | D2 强制表格 |
| 根因无数据支撑 | D4.1 必须附相关系数与分层结果 |
| 只有发生原因，没有流出原因 | D4.4 独立章节 |
| 对策无法验证 | D5 必须写量化验收标准 |
| 预防措施未文件化 | D7 每个动作都要文件编号 |
| 5Why 是推测不是事实 | 每层"证据"列 + "已验证"勾选 |
