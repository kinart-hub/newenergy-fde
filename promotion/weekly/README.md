## 填写规则

1. **北极星是"有效使用者"**（真正跑过并拿到报告的人），star 只是副产品——两条数字涨跌背离时，信前者。
2. 指标不涨时**先怀疑渠道，不要先怀疑内容**（v1 §10）。
3. 卡点必须具体到"卡在哪个人/哪个动作/哪个报错"，泛化的卡点等于没写。
4. 每月末：把 4 份周报的数字抄进方案 §2 的 90 天指标表，对照偏差 >50% 的项必须写一句归因。
