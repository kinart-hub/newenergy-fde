# 数据采集工具包（B 线）

对应《运营推广方案-v2-执行版.md》§3。目标：**用最小人力，把"格式 + 语言 + 名单"三类采集动作固定成流程。**

## 目录内容

| 文件 | 用途 | 节奏 |
|---|---|---|
| `jd_scan.py` | JD 词频采集：分析手动保存的 JD 文本，输出高频词、FDE 别名命中差表、公司名单 | 每周 30 分钟 |
| `名单与触达跟踪.csv` | 设备商/机构/高校/试用企业四类对象的触达台账 | 每次触达后登记 |
| `话术模板.md` | 设备商要格式、机构要样例、社群轻触达三类场景的原话 | 用时照抄改称呼 |

## jd_scan.py 用法

1. 在招聘网站搜「工艺工程师 / PQE / SQE / 质量工程师」+「涂布 / 辊压 / 卷绕 / 化成 / 分容 / EL / IV」。
2. 每份 JD 全文复制，存成 `jd_raw/公司名-岗位名.txt`（UTF-8，记事本另存为选 UTF-8）。
3. 运行：

```bash
python promotion/data-collect/jd_scan.py
```

4. 输出到 `promotion/data-collect/out/`：
   - `词频Top50.txt`——痛点原始语言（写文案用他们的词）
   - `别名缺口表.csv`——JD 里的数据词汇，哪些已进 FDE 别名库、哪些没有（直接喂 `lib/preprocess.py`）
   - `公司名单.csv`——公司 / 岗位 / 工序关键词，附产能信号备注列

## 红线（方案 §7 第 3 条）

只存公开 JD 文本；**不爬个人信息，不留存 HR/求职者联系方式，不做批量抓取**。本工具是离线文本分析器，不含任何爬虫逻辑。
