# 光伏硅片 / 电池片 / 组件知识库

> 用途：给 AI 与工艺工程师提供**判读依据**，不是规格书。
> 数值为行业典型参考，正式判定以企业受控规格为准。机器可读版见 `process_specs.json`。

---

## 0. 产业链与参数传导链

```
硅料 → 拉晶 → 切片 → 硅片检测 → 制绒扩散 → 镀膜印刷烧结 → 电池片 EL → 串焊 → 叠层层压 → 组件 IV/EL/热斑
         │       │         │                      │                  │         │            │
      电阻率   线张力     TTV/Warp              效率/EL缺陷        焊接温度   层压温度      Pmax/FF/Rs/Rsh
      氧碳含量 线速     厚度/崩边               断栅/隐裂          焊带涂层   层压压力      CTM/绝缘
```

**关键传导关系**

| 下游异常 | 优先回溯 | 机理 |
|---|---|---|
| 组件功率偏低（CTM 低） | 焊带电阻 → 玻璃透光 → EVA 黄变 → 电池片混档 | 封装损失叠加 |
| FF 偏低 | Rs 高（串联）或 Rsh 低（漏电） | 需先分解 Rs/Rsh 再定位 |
| 组件段隐裂 | 层压压力 → 焊接温度 → 硅片 Warp → 搬运吸盘 | 应力集中 |
| 电池片断栅 | 银浆粘度 → 印刷压力 → 网版状态 → 硅片 TTV | 印刷转移不良 |
| 热斑 | 电流混档 → 隐裂 → 旁路二极管失效 → 遮挡 | 子串失配 |

## 1. 硅片检测

### 1.1 核心参数（以 M10/182 为主流参考）

| 参数 | 典型值 | 控制口径 |
|---|---|---|
| 厚度 | 150 ±10 μm（薄片化已到 130） | 中心厚度 |
| TTV | ≤15 μm（优等 ≤10） | 五点厚度极差 |
| Warp（翘曲） | ≤50 μm（182）；≤40 μm（166） | 影响碎片率与印刷 |
| Bow（弯曲） | ≤40 μm | — |
| 电阻率 | P型 0.4-1.1；N型(TOPCon) 0.3-2.1 Ω·cm | 偏差 ≤±15% |
| 少子寿命 | P型 ≥20-50 μs；N型 ≥100 μs（优质 500+） | 材料质量核心指标 |
| 氧含量 | ≤12 ppma（优质 ≤8） | 过高→热施主、LeTID |
| 碳含量 | ≤1 ppma | 过高→影响强度与寿命 |
| 崩边/缺角 | ≤0.5 mm | 影响碎片率 |
| 尺寸 | 182 ±0.25 mm（对角线按版型） | — |

### 1.2 判读要点

- **TTV 与 Warp 是碎片率的先行指标**。薄片化趋势下，这两项的重要性持续上升。
- **电阻率异常优先查拉晶掺杂，而不是切片工序**。切片只影响几何参数，不改变化学成分。
  这是一条非常实用的归因捷径。
- **少子寿命异常指向硅料/拉晶**（金属污染、位错），下游工序无法改善它。
- 崩边在**来料阶段**就要拦截；到了组件段才发现，损失已经是 10 倍以上。

### 1.3 供应商分层的价值

硅片来料分析的第一动作永远是**按供应商做 ANOVA/Pareto**。
如果差异集中在单一供应商，问题边界立刻收窄到"来料"，
不必在自家工序里浪费时间。

## 2. 电池片 EL / PL 检测

### 2.1 缺陷分类体系（12 类标准分类）

| 类别 | 英文 | 主要成因 |
|---|---|---|
| 隐裂 | crack_line / crack_star | 应力：层压、焊接、搬运、来料翘曲 |
| 黑心 | black_core | 硅片本体缺陷（氧碳、位错）或烧结过烧 |
| 断栅 | broken_grid / broken_finger | 印刷：浆料粘度、网版、压力、TTV |
| 碎片 / 崩边 | fragment / corner_break | 机械应力、来料崩边 |
| 虚焊 / 过焊 | false_solder / over_solder | 串焊温度、压力、焊带涂层 |
| 黑斑 / 脏污 | dirty / contamination | 环境洁净度、网版残留 |
| 边缘漏电 | edge_leakage | 刻蚀/绝缘处理不良 |
| 同心圆 | concentric_circle | 拉晶/扩散不均匀 |
| 划痕 | scratch | 搬运与设备接触 |
| 缺角 | corner_break | 来料与机械损伤 |
| 错位 | misalignment | 印刷对位、串焊偏移 |

### 2.2 EL 分析的三步法（这是本知识库最重要的方法论）

EL 缺陷是最容易"看起来有结论但其实没有根因"的数据类型。
**必须先做位置聚集性分析，再谈根因**：

| 缺陷的空间分布 | 归属判断 |
|---|---|
| **随机分布** | 来料 / 电池片本体问题 |
| **沿主栅呈线状** | 焊接工序（串焊温度、压力、焊带） |
| **集中在边框 / 四角** | 层压与搬运（应力集中、吸盘局部受力） |
| **集中在固定网版位置** | 印刷网版堵孔或局部磨损 |
| **集中在单一电池片位置序号** | 串焊机对应工位的设备问题 |

**不做位置分析就直接下结论，是 EL 分析最常见的错误。**

### 2.3 判读陷阱

1. **EL 灰度 ≠ 缺陷严重度**：EL 亮度受电流密度、曝光时间、相机增益影响，
   跨批次直接比较灰度值没有意义。
2. **隐裂在层压前可能不可见**：电池片段 EL 合格，组件段出现隐裂，
   通常是层压/焊接应力导致，不是漏检。
3. **不良率的分母必须统一**：有的企业用投入数、有的用产出数，跨线对比前先确认口径。

## 3. 组件 IV 测试

### 3.1 核心参数（STC：1000 W/m²、25℃、AM1.5）

| 参数 | 典型值 | 说明 |
|---|---|---|
| Pmax | 按版型，通常 0~+5 W 正公差分档 | **必须先修正到 STC 再比对** |
| Voc | 182-72 片版型 49-51 V | 偏低→隐裂/漏电/混档 |
| Isc | 13-14 A | 偏低→遮光/混档/隐裂 |
| FF | PERC 78-81%；TOPCon 80-83%；HJT 82-85% | **FF 掉 1pt ≈ 功率掉 1%** |
| Rs | ≤0.6 Ω（依版型） | 偏高→焊带/汇流带/接触电阻 |
| Rsh | ≥50 Ω（依版型） | 偏低→漏电/隐裂/边缘绝缘/PID |
| CTM | ≥98% | 组件功率 / 电池片功率总和 |
| 绝缘电阻 | ≥40 MΩ·m² 量级（IEC 61730） | 湿漏与耐压 |

### 3.2 Rs / Rsh 分解法（功率损失定位的核心工具）

```
FF 下降
 ├─ Rs 升高  → 串联侧：焊带电阻、汇流带、主栅接触、焊接虚接、断栅
 └─ Rsh 下降 → 并联侧：漏电、隐裂、边缘绝缘失效、PID、脏污
```

**操作顺序**：
1. 先看 FF，再看 Rs/Rsh，不要直接跳到"电池片不行"
2. Rs 高 → 查串焊与汇流带（可测焊带电阻验证）
3. Rsh 低 → 查 EL 图像定位漏电点（隐裂/边缘）
4. 两者都正常但功率低 → 查 CTM（玻璃透光、EVA、电池片混档）

### 3.3 CTM 拆解

CTM < 98% 时的排查优先级：
1. **电池片电流混档**（最容易被忽视，且损失最大）
2. 焊带电阻与焊接质量（光学损失 + 电学损失）
3. 玻璃透光率与减反射膜
4. EVA/POE 黄变或透光率不足
5. 电池片本身效率分布

### 3.4 温度修正（必须做，否则数据不可用）

IV 参数对温度敏感：
- Voc 温度系数约 **-0.30 %/℃**
- Pmax 温度系数约 **-0.38 %/℃**（晶硅典型）
- Isc 温度系数约 **+0.05 %/℃**

**组件温度每差 10℃，功率就差约 4%**。
不修正到 25℃ 就做趋势分析，会把环境温度变化误判成工艺漂移——
这是光伏数据分析里最高频的错误。

## 4. 可靠性与衰减

| 衰减类型 | 首年 | 线性 | 机理与验证 |
|---|---|---|---|
| PERC 常规 | ≤2% | 0.45-0.55%/年 | 光致衰减 LID（硼氧对） |
| TOPCon | ≤1% | 0.4%/年 | N 型无硼氧对，LID 免疫性好 |
| HJT | ≤1% | 0.25-0.35%/年 | 需注意 UV 与湿热 |

| 失效模式 | 判据 | 验证方法 |
|---|---|---|
| **LeTID**（光热诱导衰减） | 户外运行数月后出现，实验室需 75℃+光照 | 暗态退火可部分恢复，以此区分 |
| **PID**（电势诱导衰减） | 负偏压 + 湿热下功率骤降，EL 整片发暗 | 负偏压湿热测试（IEC 62804） |
| **热斑** | 红外扫描局部温升 >15K | 遮挡 + 红外热成像 + 旁路二极管通断 |
| **蜗牛纹** | 隐裂处出现暗色纹路 | EL 与外观联合判定 |

**衰减分析的第一个问题**：是首年衰减还是线性衰减？
这两者机理完全不同，混在一起算会得出错误结论。

## 5. 热斑专项

**机理**：局部电池片被遮挡或失配 → 在串中被反向偏置 → 作为负载发热 → 温度可达 150℃+ → 烧毁背板。

**排查顺序**：
1. 红外热成像定位热点位置
2. 对照同一组件的 EL 图像，确认热点是否与隐裂/断栅位置对应
3. 检测对应子串的旁路二极管通断
4. 核对该组件所用电池片的电流分档是否一致（**混档是热斑的头号诱因**）

## 6. 数据采集的坑

| 坑 | 后果 | 规避 |
|---|---|---|
| IV 未做温度修正 | 把环境温差误判为工艺漂移 | 记录组件温度与监测片温度，统一修正到 25℃ |
| 光源等级未标定 | 整批数据系统性偏移 | 核查标定日期与标准片编号 |
| 不良率分母口径不一 | 跨线对比失真 | 统一为投入数或产出数，并在报告中注明 |
| EL 图像无坐标信息 | 无法做位置聚集性分析 | 要求导出缺陷在组件中的行列位置 |
| 硅片检测无供应商/机台号 | 无法分层 | 来料数据必须带供应商与机台 |
| 只导出 OK/NG 不导出测量值 | 损失 90% 信息量 | 优先导出连续量；OK/NG 仅作辅助 |
