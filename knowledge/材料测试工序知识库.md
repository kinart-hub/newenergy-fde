# 材料测试（高分子 / 导热界面 / 电磁屏蔽 / 吸波 / 复合材料）工序知识库

> 本库为 `newenergy-fde` 的「材料测试」行业切片骨架。定位：为材料表征测试类岗位/场景提供
> **统计、DOE、根因、报告** 的方法论支撑与**域参数/标准口径索引**。
> FDE 不操作实验室设备、不替代标准符合性判定；设备操作与标准解读以受控规程为准。

## 1. 适用范围（来自招聘 JD 与公开检测机构口径）

- 导热界面材料（TIM）、电磁屏蔽/吸波材料、高分子复合材料等的全流程测试。
- 关键性能：热导率/热阻/比热容/热膨胀系数/玻璃化转变温度(Tg)/热稳定性/硬度/模量/
  介电常数/磁导率/电磁屏蔽效能。
- 设备：热分析（DSC/TGA/TMA/DMA）、成分结构（FTIR/GC-MS/NMR/XRD/SEM/EDS/GPC）、
  力学（万能试验机/冲击/硬度计）、电学与电磁（高阻计/LCR/耐压仪/VNA）。

## 3. 与 FDE 能力的对接点

- **SPC / 过程能力**：测试数据（如批次间热导率、拉伸强度）的稳定性、Cpk 判读，与 JD「熟练 SPC 解读测试数据并优化流程」直接对应。
- **DOE 实验设计**：配方/工艺因子（填料含量、厚度、固化窗口、升温速率）对性能的影响筛选，DOE 安全包络可约束合规范围。
- **根因排序**：缺陷机理库（见 `process_specs.json` 的 `defect_rootcause`）提供「候选参数→机理→验证清单」结构化推理。
- **结构化报告**：输出可审计的材料测试分析报告（非实验室原始报告），保留「无依据不下判定」的责任边界。

## 4. 边界与待确认项

- 材料性能典型值因牌号差异极大，本库 `typical_range` 仅作量级兜底，**正式判定以受控规格书/控制计划为准**。
- 缺陷机理条目均带 `source`，机理取自公开检测机构资料，**现场适用性待复核**。
- 设备操作、标准符合性、CNAS 评审不在 FDE 范围内。
