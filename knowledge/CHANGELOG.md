## v1.10.0（质量护栏与盲测修复）

基于 6 套未参与开发的角色扮演数据（盲测）发现的问题修复：

- 新增 `lib/quality_guard.py`：列角色识别、长表汇总、STC 归一化、根因证据门槛、工序护栏、测试条件提示。
- 证据不足时 8D 的 D4 留空（此前即使得分 0.02 也会填写根因）。
- 目标自动选择只从「测量」列中挑选（此前会选中时间、计数、坐标列）。
- 根因候选剔除编号、时间、坐标、计数列，以及目标自身与 STC 替换前的原始列。
- 别名子串匹配护栏：「Visc」不再误配「isc」，「电池列」不再误配泛化别名「电池」。
- 工序判定证据不足或有歧义时不再静默选定工序（此前 EL 数据被判为化成）。
- 单元级热点过滤：每个水平样本数过少（ID 列 <10，其它 <5）时不计入，避免单批误排第一。
- 判定/结果类列无论目标是谁，都不再作为根因（修复 E06 中「判定=降级」的同义反复）。
- 知识库新增英文别名（CoatWt、Solid、Visc、Speed、Dryer2 等）与参数：edge_thickness、separator_thickness、roll_diameter、cell_thickness（若已存在则保持原定义）。
- 新增测试：`scripts/selftest_guard.py`（27 项）、`scripts/gen_blind_data.py` 与 `examples/blind/`（6 套盲测数据与真值）。

## v1.12.0（企业端可部署性：性能包络实测与提速）

不新增算法，只解决"企业端跑不跑得动"。

- **性能包络首次实测**（此前是无验证假设）：2 万行 × 16 列 104 s → **44.7 s**；
  5 万行由跑不完变为 **138 s**。据此确定 Skill 形态可用边界 **≤5 万行 / ≤10 MB**，写入 manifest limits。
- **瓶颈定位**：不在统计计算，在**重复解析**。剖析显示 `to_number` 在一份 2 万行数据里
  被调用 **1828 万次**（每单元格平均 57 次）；
  `vif()` 把 `table.col_index()` 写在逐行循环里，形成隐性 O(k²·n)（15 列 2 万行时找下标 450 万次）。
- 修复：按"表版本号"缓存列解析（`rows`/`columns` 变更自动作废，含 add_column 原地 append）；
  `to_number` 先 float() 直通再回退正则；VIF 的索引与列向量提到循环外。
- **新增 N 组性能护栏**：用 `to_number` 调用次数（而非墙钟时间）断言，跨机器稳定，防止回退。
- 自检 279 + 护栏 **51** 全通过；留出集 6 套结论与 1.11.0 完全一致；E01–E07 sweep 28/28。
- 遗留热点：`nelson_violations`（约 29%）与 `vif`（约 27%）。VIF 可改由相关矩阵求逆（O(k³)），留待 1.13。

**未覆盖（顺延）**：批号前缀派生分组（S2 供应商前缀）；MSA/量具 R&R；EWMA/CUSUM。

## v1.11.0（选型层整改 + 入口一致性修复）

- 新增 `lib/events.py`：缺陷事件表（一行一缺陷）识别 → 按组件汇总计数（消除伪重复）
  → 分缺陷类型做位置聚集检验（曝光加权 χ²，期望频数不足转 Fisher，BH 校正）。
- 目标列选择改为「结果型质量特性 + 可被解释的变异」打分（R² 可解释性 + 知识库 role 先验
  + T1/T2 提示分层 + 试验条件依赖惩罚），替换此前的"最大变异系数"。
- 新增 `stats.bh_adjust`，相关层与根因层的显著性一律以 BH 校正后 q 为准。
- 新增分组—行序混杂检验（`quality_guard.order_confound`，Spearman ρ>0.85 标注不可区分）。
- 新增负例判定（`negative_verdict`）：无可行动工艺因子时明说，D4 留空。
- 派生合计列（`缺陷总数`）与分档标签列（`功率档位`）排除出目标与根因候选。
- 报告新增输入文件 SHA-256 与自动决策清单（运行清单）。
- **入口一致性修复**：`lib/events.py` 仅支持相对导入，官方 CLI（`python lib/pipeline.py`）
  走脚本模式会 ImportError 并被兜底静默吞掉，导致事件表能力在 CLI 下失效、退回 1.9 行为。
  已改为按入口分支导入；`selftest_guard.py` 增 M 组（48 项），用子进程跑真实 CLI 断言两条入口齐平。
- 修正 v1.10 长表汇总取"末行字面值"的缺陷：静置/搁置工步的哨兵 0 按缺失处理，
  测量列取实体内最后一个有效观测。
