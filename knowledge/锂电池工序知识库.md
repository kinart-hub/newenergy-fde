## 0. 整线逻辑与"参数传导链"

锂电池制造的底层逻辑：**上游工序的参数波动会以放大或衰减的方式传导到下游指标**。

```
浆料 → 涂布 → 辊压 → 分切 → 卷绕/叠片 → 装配焊接 → 烘烤注液 → 化成 → 分容分选
 │       │       │      │        │           │          │        │        │
固含    面密度  压实密度 毛刺    张力/对位   焊接电阻    水分     SEI质量  容量/内阻
粘度    烘箱温度 反弹率         隔膜褶皱                 注液量    产气      K值
```

**关键传导关系（做根因分析时的优先怀疑路径）**

| 下游异常 | 优先回溯的上游参数 | 传导机理 |
|---|---|---|
| 容量一致性差 | 面密度 CV → 压实密度 → 注液量 → 化成柜温 | 容量 = 活性物质量 × 首效 × 利用率，任一环节波动都会叠加 |
| 内阻偏高 | 压实密度（过压）→ 注液量 → 极耳焊接电阻 → 化成电流 | 过压破坏孔隙结构，浸润变差，离子通路受阻 |
| 自放电 K 值超标 | 毛刺 → 隔膜损伤 → 金属异物 → 水分 | 微短路或副反应持续消耗活性锂 |
| 循环衰减快 | 水分 → SEI 质量 → 压实密度 → Overhang | SEI 不稳定会持续修复、持续消耗 |
| 产气鼓包 | 水分 → 残留溶剂（烘箱末区）→ 化成电流过大 | 电解液分解产气 |

**分析铁律**：先判断异常是"突发台阶"还是"缓慢漂移"。
- 突发台阶 → 换料、换批、参数调整、设备维修（查变更记录）
- 缓慢漂移 → 磨损、老化、沉降、季节温湿度（查趋势与保养记录）

## 1. 浆料制备（涂布的前置）

| 参数 | 典型值 | 控制要点 |
|---|---|---|
| 固含量 | 负极（水系石墨）45-55%；正极 NCM/NMP 68-75%；LFP 55-65% | 固含决定粘度与涂布流平性，是面密度的第一因 |
| 粘度 | 负极 2000-6000；正极 3000-10000 mPa·s | **必须标注剪切率与测试温度**，否则跨批次不可比 |
| 细度/粒度 | D50 依配方，D100 通常 ≤ 30 μm | D100 超标直接导致涂布划痕与针孔 |
| 沉降 | 静置后上下层固含差 ≤ 1% | 浆料超期静置会沉降，是"同一批次前后段面密度漂移"的经典原因 |

**常见误判**：把"粘度不合格"直接判定为浆料问题。实际上粘度是温度的函数，
25℃ 与 35℃ 测值可差 20% 以上。**先看测试温度，再看浆料本身。**

## 2. 涂布

### 2.1 核心参数

| 参数 | 典型值 | 控制口径 |
|---|---|---|
| 面密度（单面） | 石墨负极 90-130 g/m²；LFP 正极 170-220；NCM 正极 190-240 | 与目标值偏差 ≤ ±1.5%，纵向 CV ≤ 1.0% |
| 涂布速度 | 狭缝涂布 20-80 m/min | 提速必须同步复核烘箱能力 |
| 烘箱分区温度 | 4-8 区梯度，如 60/75/90/105/110/95/80 ℃ | 单点 ±5℃，**曲线形状比单点更重要** |
| 极片含水量 | ≤ 200 ppm（涂布后）；≤ 50 ppm（注液前烘烤后） | 卡边检测（取样位置影响极大） |
| 剥离强度 | 负极 ≥12-15 N/m；正极 ≥18-20 N/m | 依配方与测试方法 |

### 2.2 烘箱温度曲线的判读（最容易出错的地方）

烘箱不是"越热越好"，是一条**溶剂挥发速率曲线**：

| 段位 | 温度过高 | 温度过低 |
|---|---|---|
| 首区（1-2 区） | 表面先结皮，内部溶剂汽化冲破表层 → **针孔、气泡、开裂** | 浆料流动性过强 → **流挂、厚边** |
| 中段（峰值区） | 粘结剂迁移 → **掉料、剥离强度下降** | 溶剂未充分挥发 |
| 末区 | 极片过热、脆化 | **残留溶剂/NMP 超标** → 化成产气、水分高 |

**诊断要点**：针孔气泡问题，**第一动作是降首区温度 5-10℃ 做单因子验证**，
而不是先调浆料配方。这是成本最低、反馈最快的验证。

### 2.3 面密度异常的排查顺序

1. 确认固含是否在该批次配方窗口内（固含是面密度的第一因）
2. 对比涂布速度变更时间点与面密度阶跃时间点是否吻合
3. 检查浆料静置时间是否超期导致沉降
4. 检查泵速/阀开度（供料量与基材速度的匹配）
5. 测横向五点面密度，区分是纵向漂移还是横向分布问题

## 3. 辊压

| 参数 | 典型值 | 说明 |
|---|---|---|
| 压实密度 | 石墨负极 1.55-1.70；LFP 2.2-2.4；NCM 3.3-3.6 g/cm³ | 偏差 ≤ ±2% |
| 反弹率 | ≤ 3%（辊压后 24h 复测） | 反弹说明压实不稳定，影响入壳与卷芯厚度一致性 |
| 辊温 | 常温-120℃（视工艺） | 热辊可降低反弹 |

**过压 vs 欠压的后果**
- 过压：孔隙率过低 → 注液浸润困难、离子传导差 → **内阻升高、析锂风险**
- 欠压：接触不良 → **内阻升高、能量密度不足、掉料**

注意：过压和欠压**都会导致内阻升高**，所以"内阻高"不能直接反推压实方向，
必须看压实密度的实际测量值落在窗口的哪一侧。

## 4. 卷绕 / 叠片

### 4.1 张力是第一参数

| 参数 | 典型值 | 控制口径 |
|---|---|---|
| 极片张力 | 8-25 N（视幅宽） | 波动 ≤ ±5% |
| 隔膜张力 | 3-8 N | **必须显著低于极片张力** |
| 卷绕速度 | 5-60 ppm | 提速需同步复核张力闭环与 CCD 响应 |
| Overhang（负极包覆量） | 1-3 mm | 过小→析锂；过大→能量密度损失 |
| 极片错位 | ≤ 0.5 mm | CCD 在线对位 |

**张力的三个经典问题**
1. 张力过大 → 极片拉伸 → 掉料、断片
2. 张力过小 → 松卷 → 褶皱、层间间隙
3. **隔膜张力 ≥ 极片张力** → 隔膜被拉伸后回缩 → **起皱**（这是最常见的隔膜褶皱原因）

### 4.2 Hi-pot 短路测试

- 典型 250-500 V DC，判定阈值按机型（常见绝缘电阻 ≥20 MΩ 或漏电流 ≤1 μA）
- **Hi-pot 不良是拦截内短路的最后关口**，出现批量不良必须立即停线排查
- 排查方向：毛刺（分切刀具磨损）、极片错位、隔膜针孔、金属异物
- **分析方法**：按卷绕机号/模切刀号做 Pareto 分层，若集中在单台设备 → 设备问题；
  若分散 → 来料（隔膜/极片）问题

### 4.3 毛刺

- 极片分切毛刺典型要求 ≤10 μm，且不得超过隔膜厚度的 1/2
- 毛刺是内短路的头号物理原因，且**具有刀具寿命相关性**（随生产数量递增）
- 分析时要看"毛刺高度 vs 刀具生产数量"的散点关系，而非只看毛刺是否超标

## 5. 注液

| 参数 | 典型值 | 说明 |
|---|---|---|
| 注液量 | ±1.5% | 不足→浸润不良、内阻高；过量→产气、漏液 |
| 露点 | ≤ -40℃（部分 ≤-45℃） | **必须连续监控，单点抽检无意义** |
| 电芯水分 | ≤ 50 ppm | 超 100 ppm 会显著恶化 SEI 与循环 |
| 静置浸润 | 12-48 h | 不足→化成产气、容量偏低 |

**水分是锂电池寿命的头号杀手**。水分超标会：
与 LiPF6 反应生成 HF → 腐蚀正极、破坏 SEI → 产气、内阻升高、循环跳水。

**判读要点**：如果看到"容量衰减快 + 产气 + 内阻升高"三连，
第一怀疑是水分，而不是电解液配方。

## 6. 化成 / 分容

### 6.1 化成的本质

化成是**在负极表面生长 SEI 膜**的过程。SEI 的质量决定了电芯的：
首效、内阻、自放电、循环寿命。

| 参数 | 典型值 | 影响 |
|---|---|---|
| 化成电流 | 0.02-0.1 C | 过大→SEI 疏松、不可逆容量高；过小→工时长 |
| 化成温度 | 25-45℃，柜内温差 ≤±2℃ | 温度决定 SEI 成分，温差直接破坏一致性 |
| 夹具压力 | 0.2-0.6 MPa | 影响界面接触与产气排出 |
| 首效 | 石墨体系 88-94% | 低于基线 2pt → 查水分与 SEI |

### 6.2 分容关键指标与判读

| 指标 | 控制口径 | 异常时的含义 |
|---|---|---|
| 容量 | 配组 ±1% | **双峰分布 = 混入异常批次**（这是最有价值的信号） |
| ACIR | 组内 CV ≤8% | 偏高→焊接/压实/注液/电解液电导率 |
| DCR | 组内 CV ≤10% | 测试条件（SOC/脉冲/时长）必须先锁定 |
| 自放电 K 值 | ≤0.5 mV/d（部分 ≤0.1 mV/h） | **微短路最灵敏的指标，比容量更早暴露问题** |

### 6.3 三高判定法（化成段的实用判读规则）

| 组合 | 指向 |
|---|---|
| 容量低 + 内阻高 + K 值高 | 微短路（毛刺/异物）或水分超标 |
| 容量低 + 内阻正常 + K 值正常 | 活性物质量不足（面密度/压实）或注液量不足 |
| 容量正常 + 内阻高 + K 值正常 | 接触电阻问题（焊接/极耳/夹具） |
| 容量正常 + 内阻正常 + K 值高 | 早期微短路，需延长搁置复测确认 |

### 6.4 柜间差异分析方法

化成柜的通道温度差异是容量一致性的隐形杀手：
1. 按柜号/通道分组做 ANOVA
2. 若通道间差异显著（p<0.05）→ 查柜内风道与温控
3. 若柜间差异显著 → 查柜体保温与循环水路
4. **必须先排除柜温因素，才能把容量差异归因到上游工序**

## 7. 不良 - 根因速查表

| 不良现象 | 优先怀疑参数（按顺序） | 快速验证动作 |
|---|---|---|
| 面密度超差 | 固含 → 泵速/阀开度 → 涂布速度 → 间隙比 | 测五点横向面密度，确认是纵向还是横向问题 |
| 针孔气泡 | 烘箱一区温度 → 浆料脱泡 → 浆料温度 → 涂布速度 | 一区温度降 5-10℃ 单因子验证 |
| 厚边 | 粘度 → 间隙比 → 表面张力 | 测横向五点，确认边缘是否偏高 |
| 掉料 | 烘箱峰值温度 → 压实密度 → 张力 → 粘结剂 | 测剥离强度，反查烘箱曲线 |
| 极片错位 | 张力稳定性 → 卷绕速度 → CCD 对位 → 卷针夹持 | 把张力曲线与错位时刻做时间对齐 |
| 隔膜褶皱 | 隔膜张力（是否≥极片张力）→ 张力波动 → 放卷制动 | 直接对比两条张力曲线的比值与带宽 |
| 内短路 | 毛刺 → 极片错位 → 隔膜针孔 → 金属异物 | 按设备/刀具做 Pareto，解剖定位短路点 |
| 自放电超标 | K 值分布（双峰？）→ 毛刺 → 水分 → 异物 | K 值直方图看是否双峰 |
| 容量一致性差 | 面密度 CV → 化成柜温 → 注液量 → 压实密度 | 按柜通道 ANOVA + 容量直方图 |
| 内阻偏高 | 区分 ACIR/DCR → 压实密度 → 注液量 → 焊接电阻 | 同步偏高→本体；仅 DCR 高→极化 |

## 8. 数据采集的坑（做分析前必须确认）

1. **测试条件未锁定**：粘度没标温度、DCR 没标 SOC、内阻没标频率 → 数据不可比
2. **取样位置不一致**：面密度取左中右哪一点、水分取极片哪个位置 → 数据不可比
3. **时间戳精度不足**：只有日期没有时分 → 无法与设备参数变更做时间对齐
4. **缺少分组维度**：没有设备号/批次号 → 无法区分全局问题与单台设备问题
5. **比率直接相加**：不同产量的班次不良率直接求平均 → 权重错误，必须用产量加权
6. **测量系统误差未评估**：量具 R&R 未做 → 波动可能来自测量而非工艺
   （经验规则：测量系统变异应 < 过程变异的 10%，< 规格带的 30%）
